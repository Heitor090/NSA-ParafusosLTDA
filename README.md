## 📌 Sobre o projeto

Este projeto consiste em uma **landing page responsiva** desenvolvida para a N S A Comércio de Parafusos.

O objetivo é criar uma presença digital para a empresa, permitindo que visitantes conheçam seus produtos e serviços, encontrem a loja, visualizem imagens do estabelecimento e entrem em contato para solicitar um orçamento.

O projeto foi desenvolvido utilizando tecnologias web fundamentais:

* **HTML5** para estruturação;
* **CSS3** para estilização e responsividade;
* **JavaScript** para interações e funcionalidades da página.

---

## 🚀 Funcionalidades

### 🏠 Página inicial

Apresentação da empresa com uma seção principal contendo:

* Identidade visual da N S A;
* Chamada para ação;
* Apresentação dos principais produtos;
* Botões de navegação para orçamento e produtos.

### 🔩 Produtos

Seção destinada à apresentação das principais categorias comercializadas pela empresa:

* Parafusos;
* Ferramentas;
* EPIs;
* Acessórios.

### 📍 Localização

Área dedicada à localização da loja, permitindo ao visitante:

* Visualizar a localização através do Google Maps;
* Consultar informações sobre o estabelecimento;
* Conhecer o estacionamento disponível para clientes.

### 🏪 Sobre a empresa

Seção institucional apresentando a empresa e sua proposta, acompanhada por um **carrossel automático de imagens da loja**.

### 💬 Solicitação de orçamento

Formulário para que o cliente possa informar:

* Nome;
* Telefone;
* Produto de interesse;
* Mensagem.

Após o preenchimento, a solicitação pode ser encaminhada através do **WhatsApp**.

### 📱 Design responsivo

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela:

* 💻 Desktop;
* 💻 Notebook;
* 📱 Smartphone;
* 📲 Tablet.

O menu de navegação também possui comportamento adaptado para dispositivos móveis.

## ▶️ Como executar o projeto

Como o projeto utiliza HTML, CSS e JavaScript puro, não é necessário instalar dependências ou utilizar um servidor backend.

### 1. Clone o repositório

```bash
git clone https://github.com/Heitor090/NSA-ParafusosLTDA.git
```

### 2. Entre na pasta

```bash
cd NSA-ParafusosLTDA
```

### 3. Execute o projeto

Abra o arquivo:

```text
index.html
```

no navegador.

### 💡 Recomendação

Durante o desenvolvimento, você pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar as alterações automaticamente.
